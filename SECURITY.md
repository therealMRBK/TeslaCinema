# Security policy

TeslaCinema gives access to a browser, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on this repository
(<https://github.com/therealMRBK/TeslaCinema/security/advisories/new>).

Include what you found, how to reproduce it, and which version or commit. You will get an answer as soon as possible.

## Supported versions

Only the latest release and the `main` branch receive fixes.

## Hardening checklist for users

See [docs/security.md](docs/security.md): use https, a long password, keep the port on loopback, rebuild regularly so Chrome stays current.
